# Мобильная вёрстка: сверка с макетом по полосам контента

Замер и правки от 2026-07-27. Инструмент — `site/scripts/qa-bands.mjs`: оба изображения сводятся
к списку горизонтальных полос контента (строк текста, картинок, таблеток), позиции сравниваются
относительно первой полосы.

## Почему для мобильной меряем полосы, а не проценты

Мобильные эталоны Figma отдал уменьшенными (283px вместо 320 — автомасштаб рендера), и при
сравнении их приходится растягивать обратно. Растянутый эталон размыт, поэтому даже идеально
совпадающая строка текста даёт заметный процент несовпадения: пиксель-метрика на мобильной
показывает шум размытия, а не качество вёрстки. Полосы контента от размытия не зависят —
поэтому приёмка мобильной идёт по ним.

Инструмент проверен на секции, которая заведомо сделана верно: «Тебе к нам, если ты» — 21 полоса
из 21 совпадает в пределах ±3px при нулевой разнице высоты.

## Важное ограничение: эталоны — из предыдущего файла Figma

Мобильные слайсы нарезаны из фрейма **18535px**. Дизайнер прислал новый файл, где мобильная —
**19901px**. Рост объясняли четырьмя карточками преподавателей, но арифметика не сходится: четыре
карточки по нашим метрикам дают ≈1561px, а фрейм вырос на 1366. Разница ~195px означает, что
какие-то секции в новом файле изменились ещё и по высоте.

Поэтому правились только те расхождения, где значение макета читается однозначно и подтверждается
десктопной версией той же секции (пропорция интерлиньяжа, высота элемента). Оставшиеся —
осознанно ждут рендера нового мобильного фрейма: подгонять их под устаревший эталон значит
рисковать увести вёрстку от актуального макета.

**Что нужно, чтобы закрыть остаток:** один рендер узла `271:2313` (320×19901) из файла
`MPSaLex5LnqHJQLC5f9KxP`, страница «new final». Дальше работа механическая:

```bash
node scripts/qa-bands.mjs 06-kak      # покажет, что именно съехало
# правка значений в компоненте
node scripts/qa-bands.mjs 06-kak      # проверка
```

Получить рендер сейчас не удалось: Figma REST API держит 429 на `/v1/files`, `/v1/images` и
`/nodes` вторые сутки (лимит на аккаунт, не на ключ). Обходной путь — ручной экспорт фрейма из
редактора, как это было сделано для секции преподавателей.
