## Расхождение 2: в тексте новости нет вставных изображений

Дизайнер нарисовал **четыре варианта компоновки** страницы новости — различаются только тем,
как картинки встроены в текст:

| Макет | Высота | Что внутри текста |
|---|---|---|
| Новость 1 `391:57` | 2579 | ничего — только обложка сверху ✅ реализовано |
| Новость 2 `391:872` | 3001 | одна картинка между абзацами |
| Новость 3 `391:988` | 3894 | две картинки, каждая на своей строке |
| Новость 4 `391:1107` | 3894 | две картинки **в ряд** + одна отдельная ниже |

Мобильные версии: `391:1690`, `392:1864`, `392:1950`, `392:2042`.

Сейчас текст новости у нас — только абзацы: `body` разбивается по пустой строке. Вставок нет.

**Что из этого следует:**
1. В данных новости нужен формат, допускающий блоки-изображения (одиночные и парные), а не
   только сплошной текст.
2. В админке контент-менеджеру нужна возможность вставлять картинки в тело новости —
   сейчас загружается только обложка.

Объём заметный: меняется схема хранения новости, страница новости и редактор в админке.
